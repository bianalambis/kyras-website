# K’YRAS – Underground Club Website Concept

## Project Description
K’YRAS is a multi-page static website concept for a fictional underground club, designed with a Y2K cyber rave aesthetic. The site focuses on bold visuals, layered layouts, and experimental styling to create an immersive digital experience. The goal of this project was to explore visual design through HTML and CSS while maintaining a cohesive look and feel across multiple pages using an AI-assisted workflow.

---

## Core Features
- Multi-page layout (Home, About, Events, Gallery, Contact)  
- Custom styling with neon accents and layered visual effects  
- Grid-based layouts for flexible content organization  
- Image gallery with overlay and texture effects  
- Consistent visual identity across all pages  

---

## Technologies Used
- HTML  
- CSS  
- JavaScript (minimal, if any)  
- GitHub for version control  
- Claude AI for layout generation, debugging, and design exploration
